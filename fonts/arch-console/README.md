# ForgeMono Workbench Console NF

GNOME Console / VTE 使用的四字重衍生字体。原文字、图标和 COLR 几何保留；hhea / OS/2 的行高调整为 1.42 em，基线居中，用于原来的 1.42 几何银行。

由 `scripts/build-arch-fonts.py` 从原 ForgeMono Geometry 6 NF 构建。授权见上级 `OFL.txt`、`licenses/` 和配置根目录 `THIRD_PARTY.md`。

144 个接缝字形（每字重）的基底轮廓包含原 COLR 全部图层，用完整包围盒避免 VTE 截掉标签上沿和侧边。彩色图层、色板、字符映射、字宽与普通字形保持原样。
